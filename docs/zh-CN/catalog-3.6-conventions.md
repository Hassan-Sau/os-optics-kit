# 处方中的目录 3.6 约定

本工具包已在上基本地构建的目录 3.6 版本（`2026-11-24.1`）上离线检查。以下是每个案例和每份新处方都遵循的约定；
先用三个案例（`achromatic-imaging`、`mirror-alignment`、`midwave-infrared-imager`）确立，再应用到全部十八个案例。

## 玻璃名称：引用目录材料 id

裸牌号并不唯一。3.6 目录带有按厂商区分的记录（如 `CDGM_F2`、`SCHOTT_...`），许多玻璃还另有一条以裸牌号命名的
记录。`F2` 是文档中的例子：裸名既可读作 CDGM 的玻璃，也可读作 SCHOTT 的玻璃，两者是不同的熔炼、系数不同。
因此处方一律写**目录材料 id**，不只写商品牌号：

```
"media": ["CDGM_F2"]        # 权威：目录记录
"media": ["F2"]             # 有歧义：拒绝，并选择一个 id
```

id 就是记录中的 `material_id`；牌号、别名与厂商保留在记录的 `identity` 块中供显示。重新记录案例期望值时，
引用的 id 属于该变化的理由之一。

## 波长：声明真空或空气

3.6 材料在 `index_reference` 中声明自己的口径：公式取哪种波长（空气或真空）、在哪个温度、折射率是否相对空气。
处方不得依赖默认值，由此有两点后果：

- 波长列与其来源一起声明是真空还是空气，目录里的真空波段不会被悄悄当作空气波段复用。
- 0.14 引擎总是把工程环境的空气作为环境介质下放（给定温度与压力下的空气材料，20 °C、101325 Pa 时折射率约
  1.000275）。未声明环境的工程得到标准空气；此前的引擎环境介质恰为真空。仅此一项就使一个案例移动：
  `beam-expander` 的腰半径在折射率为 1 的空气下为 1.99607 mm，在标准空气下为 1.95 mm；把案例副本的
  `environment.pressure_pa` 设为 0 可精确复现旧值。案例因此显式声明环境。

## 未知体吸收：报告边界，不报数值

3.6 目录只有少数材料带有实测光谱 `bulk_loss`，多数记录没有。没有实测损失不等于“无吸收”。引擎把通过此类路径的
功率报告为边界并给出原因（`BULK_LOSS_NOT_ESTABLISHED`）：量状态为 `BOUNDED`，取值是一个区间（例如
`aspheric-lens` 像面为 0 W 至 8.5 mW），其上的目标留在模型之外而不会被评估。因此案例

- 不把这类数值与容差比较，也不当作精确值记录；
- 在报告该量的地方写明区间与原因；
- 把点名该原因的 `PARTIAL` 执行视为预期结果，而不是失败。

## 本轮结果

对 os-optics 0.14.0 与目录 `2026-11-24.1`：三个探测案例的全部目标结论不变；`achromatic-imaging` 与
`mirror-alignment` 只有记录的引擎输入哈希不同，`midwave-infrared-imager` 从 `PARTIAL` 变为 `COMPLETED`
（玻璃路径现在被计算）。全部十八个案例呈现同一模式：移动的只有三个玻璃案例的执行状态与记录的输入哈希，
锁定旧目录版本的案例需要更新目录钉。没有放宽任何容差。
